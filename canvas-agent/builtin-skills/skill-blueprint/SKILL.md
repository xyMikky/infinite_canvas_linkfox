# Skill 拆解蓝图

你交付的是**一张可预览的 Skill 架构蓝图**（单文件 `.canvas.tsx`），不是聊天式总结。读者看完应当明白：这个 Skill 什么时候被触发、吃什么输入、按什么流程干活、有哪些不可逾越的门禁、吐出什么产物、产物去哪里。

## 何时使用

- 「拆解这个 Skill」「分析它的架构 / 运作方式」「画出它的流程图」
- 「这个 Skill 的门禁 / 规范 / 上下游是什么」
- 新写完一个 Skill 想审查结构；或接手别人 Skill 前想快速看懂

不要用本 Skill 去做：修改目标 Skill、执行目标 Skill 的任务、生成与拆解无关的报告。

## 目标 Skill 从哪来（按顺序定位）

1. 画布连线或 `@` 引用的 Skill 文件夹节点（提示里会带文件清单与本地路径）。
2. 用户点名的已安装 Skill：去工作空间 `.agents/skills/<name>/` 找。
3. 都没有时，用用户消息里给出的 SKILL.md 正文。
4. 定位失败就直说缺什么，不要凭名字猜内容。

## 拆解前必读（有什么读什么）

- `SKILL.md` 全文：frontmatter 的 name/description 是触发面；正文是流程、规范与红线的唯一事实来源。
- `agents/openai.yaml`：显示名、简介、默认提示词（用户入口形态）。
- `scripts/`、`references/`、`examples/`、`assets/`：逐个记下文件名与职责；脚本要看清入参与产物。
- 任何读不到或未声明的信息，蓝图里写「未声明」，**禁止编造**。

## 拆解框架（蓝图的八个板块，按此取材）

| 板块 | 内容 | 取材 |
| --- | --- | --- |
| 1 身份卡 | 名称、显示名、一句话目标、适用场景标签 | frontmatter + openai.yaml |
| 2 触发面 | 显式引用（`$name`）、自动触发关键词、默认提示词 | description 逐词拆出 |
| 3 上游输入 | 期望的输入类型与来源、前置依赖（工具 / 环境 / 网络 / MCP） | 正文「何时使用」「输入」等章节 |
| 4 执行流程 | 步骤、判定分支、回退路径 | 正文流程性内容，提炼成节点与边 |
| 5 门禁红线 | 硬性规则、禁止事项、质量红线，逐条列出 | 正文「硬性规则」「红线」「禁止」等 |
| 6 产物与下游 | 产物类型 / 格式 / 数量上限、落地位置、谁来消费 | 正文「产物选型」「输出协议」 |
| 7 文件构成 | 目录树 + 每个文件一句话职责 | 实际文件清单 |
| 8 盲区提示 | SKILL.md 没覆盖的场景、规则间的冲突（如有） | 你的分析，标注为「分析」而非事实 |

信息不足的板块保留标题并写「未声明」，让读者看见缺口本身也是拆解结果。

## 版式要求（.canvas.tsx）

产物规范与组件 API 完全遵循同目录的 `generate-canvas-report` Skill（单文件、只 import `"infinite-canvas"`、default export、数据内联、禁 fetch；版式细节与自绘写法参考它的 `examples/` 两份图鉴）。本 Skill 的推荐选型：

| 板块 | 首选组件 |
| --- | --- |
| 身份卡 + 触发面 | `H1` + `Text` + `Pill`（触发词一词一个 Pill）+ `Stat` |
| 上游输入 / 产物下游 | 双栏 `Card` 对照，或 `FlowDiagram direction="row"`（输入 → Skill → 产物三段） |
| 执行流程 | `FlowDiagram`：步骤用 process、门禁判定用 decision（tone warning）、失败回退画回边 |
| 门禁红线 | `Callout tone="danger"`（禁止）+ `Callout tone="warning"`（约束）+ 勾选式清单 |
| 规范 / 产物选型 | `Table` |
| 文件构成 | `CollapsibleSection` 内嵌目录树（等宽文本或缩进列表） |
| 盲区提示 | `Callout tone="neutral"`，标题注明「分析」 |

结构顺序建议：身份卡 → 触发面 → 上下游总览（一张 FlowDiagram 或双栏）→ 执行流程大图 → 门禁红线 → 规范表 → 文件构成 → 盲区。流程图是主角，给足高度；不要退化成纯文字清单堆砌。

## 硬性规则

1. 蓝图中每一条事实（触发词、规则、产物格式、文件名）都必须能在目标 Skill 的文件里找到出处；你的推断只能出现在「盲区提示」板块并标注「分析」。
2. 文件名英文，以 `.canvas.tsx` 结尾（例如 `skill-blueprint-generate-canvas-report.canvas.tsx`）。
3. 一轮只交这一个文件；不要顺手改目标 Skill 的任何文件。
4. 文案默认中文；引用原文关键词时保留原语言。

## 产物协议

- 沙箱档：用文件块协议输出，块外不写任何字：

```text
<<<FILE:skill-blueprint-xxx.canvas.tsx>>>
...源码...
<<<END>>>
```

- 联网执行档：把文件写到本轮 `outputDir`，不要输出文件块。
